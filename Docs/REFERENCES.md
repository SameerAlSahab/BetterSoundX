# References

- Apple, [Creating an Audio Server Driver Plug-in](https://developer.apple.com/documentation/CoreAudio/creating-an-audio-server-driver-plug-in): official minimal HAL driver sample and installation model.
- Apple, [AudioServerPlugInDriverInterface](https://developer.apple.com/documentation/coreaudio/audioserverplugindriverinterface): driver callback contract.
- Apple, [DoIOOperation](https://developer.apple.com/documentation/coreaudio/audioserverplugindriverinterface/doiooperation): real-time audio operation callback.
- Apple, [Core Audio](https://developer.apple.com/documentation/coreaudio/): HAL APIs.
- Apple, [Create audio drivers with DriverKit (WWDC21)](https://developer.apple.com/videos/play/wwdc2021/10190/): distinction between AudioServerPlugIn virtual devices and physical AudioDriverKit devices.
